Omarchy Calendar 개인정보처리방침

이 방침은 안성훈이 운영하는 개인용 Omarchy Calendar의 Google Calendar 읽기 전용 연동과 이 안내 사이트에 적용합니다.

이 연동은 tmn73.calendar 플러그인과 Google Workspace CLI(gws)를 사용합니다. 사용자가 별도로 설정하는 일정 편집, 다른 캘린더 백엔드 또는 다른 앱의 데이터 처리는 이 방침의 범위에 포함하지 않습니다.

1. 접근하는 정보와 권한

사용자가 Google 로그인에서 허용한 범위 안에서 다음 정보를 처리합니다.

  • 계정 식별과 인증에 쓰이는 이메일, 기본 프로필 정보 및 OAuth 인증 정보입니다. 로그인 요청에는 openid, userinfo.email, userinfo.profile이 포함됩니다.
  • 캘린더 식별자, 이름, 색상, 접근 역할과 기본 알림 설정을 읽습니다.
  • 일정 식별자, 제목, 시작·종료 시각, 종일 여부, 설명, 장소, 회의·일정 링크, 일정 유형, 본인의 참여 응답과 알림 설정을 읽습니다. API 응답에는 주최자나 참석자 등 관련 정보가 포함될 수 있습니다.

캘린더 권한은 https://www.googleapis.com/auth/calendar.readonly입니다. 이 권한은 계정이 접근할 수 있는 캘린더에 적용하며, 표시할 캘린더는 위젯 설정에서 선택할 수 있습니다. 이 설정은 일정 생성·수정·삭제 권한이나 Gmail, Drive 파일, 연락처 권한을 요청하지 않습니다. Google 비밀번호는 이 앱이나 안내 사이트가 받지 않습니다.

2. 정보를 사용하는 목적

계정 식별과 인증 정보는 본인이 허용한 Google Calendar에 연결하고 접근을 유지하는 데 사용합니다. 캘린더와 일정 정보는 Omarchy 위젯에서 일정 및 알림을 표시하는 데 사용합니다.

Google API에서 받은 데이터와 그로부터 만든 데이터는 판매, 광고, 신용평가 또는 범용 AI·머신러닝 모델의 학습·개선에 사용하지 않습니다. 이 연동에는 캘린더 내용을 운영자 서버로 수집하거나 분석하는 기능이 없습니다.

3. 저장 위치와 보관 기간

  • OAuth 자격 증명은 사용자 컴퓨터의 gws 저장소에서 관리합니다. 이 설정은 캘린더 전용 ~/.config/gws-omarchy-calendar/ 프로필을 사용합니다. 자격 증명 보호 방식은 gws와 OS 키링 설정을 따릅니다.
  • 위젯 표시용 일정 캐시는 ~/.local/state/omarchy/calendar-events.json에 저장합니다. 이 JSON 파일 자체는 암호화하지 않습니다. 사용자 계정 권한과 기기 보안을 유지해야 합니다.
  • 기본 동기화 범위는 과거 7일과 향후 60일입니다. 성공한 동기화는 캐시 파일을 교체합니다. 동기화가 중지되거나 실패하면 마지막 캐시가 남을 수 있습니다. 접근을 해제해도 로컬 파일은 자동으로 지워지지 않습니다.
  • 인증 정보와 마지막 캐시는 사용자가 삭제할 때까지 남을 수 있습니다. 시스템 로그나 사용자 백업에 남은 복사본은 해당 시스템의 보관·삭제 설정을 따릅니다.

일정 캐시나 로그가 공개 저장소 또는 공개 웹페이지에 올라가지 않도록 관리해야 합니다.

4. 외부 연결과 제3자 처리

로그인·토큰 갱신과 일정 조회는 Google의 인증 및 Calendar API에 HTTPS로 연결하여 처리합니다. 운영자는 별도의 캘린더 데이터 수집 서버를 제공하지 않습니다.

사용자가 회의, 지도, 일정 또는 다른 외부 서비스 링크를 선택하면 브라우저나 해당 서비스가 열립니다. 이때 IP 주소와 링크에 포함된 위치·식별자 등이 해당 서비스에 전달될 수 있으며, 그 서비스의 개인정보처리방침이 적용됩니다.

이 안내 사이트는 캘린더 데이터나 OAuth 토큰을 입력받지 않는 정적 페이지입니다. 자체 광고·분석 스크립트, 로그인 폼 또는 쿠키 설정 코드를 포함하지 않습니다. GitHub Pages로 게시할 경우 GitHub가 보안·운영 목적으로 접속 정보를 처리할 수 있으며, GitHub 개인정보처리방침이 적용됩니다.

Google 데이터는 이 방침에 설명한 기능과 사용자가 명시적으로 선택한 외부 연결의 범위를 벗어나 제3자에게 제공하지 않습니다. 지원 과정에서 데이터 확인이 필요하면, 사용자의 명시적 동의를 먼저 받습니다. 인증 코드·토큰·클라이언트 비밀값은 지원 문의에 보내지 마세요.

5. Google API 데이터의 제한적 사용

Omarchy Calendar는 Google API에서 받은 정보의 사용과 다른 앱으로의 전송에 Google API Services User Data Policy의 Limited Use(제한적 사용) 요구사항을 적용합니다. 정보는 이 방침에 공개한 사용자용 캘린더 기능에 한정하여 처리합니다.

6. 접근 해제와 로컬 데이터 삭제

  1. Google 계정의 서드파티 연결 관리에서 연결된 캘린더 앱을 찾아 접근을 해제할 수 있습니다.
  2. 사용자 컴퓨터에서 omarchy-calendar-sync.timer를 중지하고 비활성화하면 주기적 동기화를 멈출 수 있습니다.
  3. 캘린더 전용 프로필의 자격 증명과 일정 캐시를 삭제할 수 있습니다. 로컬 백업·로그가 있다면 별도로 관리해야 합니다. 별도 Gmail 프로필이나 Google 원본 일정은 이 로컬 삭제의 대상이 아닙니다.

Google 접근 해제는 기존 로컬 캐시를 삭제하지 않으며, 로컬 파일 삭제만으로 Google에 부여한 접근 권한이 해제되지는 않습니다. 둘 다 원하면 각 작업을 수행해야 합니다.
